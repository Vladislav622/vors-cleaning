# Адаптация под другую компанию

## Меняется в кабинете, без программиста

| Раздел | Что |
|---|---|
| Тарифы | Цены всех вариантов, минимальный заказ, % сильных загрязнений, % второй стороны матраса, выезд за город, шаг округления, валюта |
| Компания | Название, подзаголовок, город, территория, телефон, WhatsApp, Telegram, email, часы работы, юр. лицо для политики, акцентный цвет, демо-плашка |
| Игра | Выключена / без скидки / с бонусом; сумма бонуса, срок, минимум следующего заказа |
| Персонажи | Характер реплик (весёлый, спокойный, немногословный), показ лиц и рук, показ реплик |
| Доступ | Смена пароля, выход |

Пустой телефон или мессенджер просто не показывается — заглушки «как настоящий номер» на сайте нет.

## Требует правки исходников

| Что | Где | Оценка |
|---|---|---|
| Логотип | `src/app/layout.tsx` (знак `.logo-mark`), `scripts/make-icons.mjs` | 0,5–1 ч |
| PWA-иконки и OG-картинка | `node scripts/make-icons.mjs "#ЦВЕТ"` | 15 мин |
| Полная палитра и шрифт | `src/app/globals.css` (токены в `:root`) | 1–2 ч |
| Тексты страниц, реплики персонажей | `src/components/Configurator.tsx`, `src/lib/phrases.ts`, `src/app/*/page.tsx` | 1–3 ч |
| Цвета и форма 3D-мебели | `blender/generate_models.py` → `npm run models:optimize` | 2–6 ч |
| Новые модели (свои GLB) | положить в `assets-src/glb/<вариант>.glb`, оптимизировать; узлы `Upholstery`, `Face_*`, `Arm_L/R` для лиц, рук и игры | 3–8 ч |
| Новые варианты в существующих категориях | `src/lib/catalog.ts` + модель + цена | 1–3 ч |

## Оценивается отдельно

Новые категории услуг со своей логикой, онлайн-оплата, расписание и календарь мастеров, несколько ролей и сотрудников, CRM-интеграции, уведомления (Telegram-бот, SMS, email), мультиязычность, несколько городов с разными прайсами.

## Регулярные расходы

| Статья | Ориентир |
|---|---|
| Хостинг Next.js (Vercel Hobby / свой VPS) | 0 — от ~5 $/мес; Vercel Pro 20 $/мес для коммерческого использования |
| PostgreSQL (Neon / Supabase free или платный тариф) | 0 на старте; 19–25 $/мес при росте |
| Домен | ~10–15 $/год |
| Платных API на каждый запрос нет | Реплики заранее написаны, 3D работает в браузере, нейросети не используются |

Цены сторонних сервисов — ориентир на ноябрь 2026, проверяйте на сайтах провайдеров.

## Передача заказчику

1. Создать базу и хостинг на аккаунт заказчика, задать переменные окружения.
2. `npm run db:migrate`, `npm run db:seed`.
3. Войти в `/admin`, сменить пароль, заполнить «Компанию» и «Тарифы», выключить демо-плашку.
4. Проверить политику обработки данных с юристом.
